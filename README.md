# Matrix Password Generator для NapoleonIT

Интерактивный **Генератор паролей** с возможностью выбирать количество рандомно-генерируемых символов, построенный на чистом VanillaJS и покрытый тест-кейсами. Реализовано адаптивное PWA-приложение с поддержкой автономной работы и установки на любое устройство.

Приложение в _[Live-режиме](https://password-generator-src.vercel.app/)_

Руководство по тестированию: [TESTING.md](./TESTING.md).

---

# 1. Запуск проекта:

```bash
# Установка зависимостей:
npm i

# Запуск проекта:
npm run dev

# Запуск тестов:
npm run test
```

Запустите проект через локальный сервер. Рекомендуется плагин **Live Server** для VS Code.
   - *Важно:* Открывайте Live Server непосредственно на файле `src/index.html` или настройте корень сервера на папку `src`.

## Отсановка проекта:

```txt
Ctrl + C
```

# 3. Описание архитектуры:

```bash
password-generator/
                  ├──src/       # Корневая папка веб-сайта (Root Directory для Vercel)
                  │     ├── core/                # Ядро проекта
                  │     │       ├── BaseGenerator.js               # Абстрактный класс генератора
                  │     │       ├── FactoryGenerator.js            # Фабрика для создания генераторов
                  │     │       ├── handleGenerateClick.js         # Обработчик клика генерации
                  │     │       ├── passwordService.js             # Сервис сборки и перемешивания пароля
                  │     │       ├── constants/                     # Объявление констант символов
                  │     │       └── generators/                    # Классы конкретных генераторов (a-z, A-Z, 0-9, !@#)
                  │     ├── images/              # Иконки приложения (192px, 512px, favicon)
                  │     ├── test/                # Тест-кейсы проекта 
                  │     │       ├── backend/                       # Тесты для внутренней логики кода
                  │     │       └── frontend/                      # Тесты для проверки сценарий пользователя
                  │     ├── index.html           # Главная страница приложения
                  │     ├── index.js             # Инициализация DOM-обработчиков
                  │     ├── sw.js                # Сервис-воркер (Динамическое офлайн-кэширование)
                  │     ├── manifest.json        # Манифест PWA (Иконки, цвета, режим отображения)
                  │     └── global.css           # Неоновые стили и адаптивная верстка
                  │    
                  ├── .prettierrc         # Конфигурация форматирования кода (единый стиль отступов и кавычек)  
                  ├── .eslint.config.js   # Настройки статического анализатора (поиск ошибок и проверка качества JS-кода)
                  ├── jest.config.mjs     # Конфигурация среды тестирования Jest (для запуска юнит-тестов)
                  ├── package.json        # Манифест проекта
                  ├── README.md           # Главная документация проекта (описание, стек и инструкция по запуску)
                  └── TESTING.md          # Руководство по тестированию PWA и UI

```

# 5. Особенности:

- **Архитектура на основе Фабрики:** Масштабируемая структура генераторов под каждый тип символов.
- **PWA Поддержка:** Возможность установки на Android/iOS и полноценная работа в офлайн-режиме.
- **Тестирование интерфейса (UI/UX):** Возможность тестирования кода под различные сценарии пользователя.
- **Безопасный буфер обмена:** Автоматическое копирование готового пароля в один тап по инпуту без вызова клавиатуры.
- **Динамический UI:** Адаптивная верстка, кастомные чекбоксы и стилизованный ползунок под неоновый стиль.
