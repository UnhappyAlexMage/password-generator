# Руководство по тестированию Matrix Password Generator

В данном документе описаны шаги для ручного тестирования ключевого функционала приложения: отзывчивости интерфейса, работы буфера обмена и механизмов PWA.

---

# 1. Тестирование интерфейса (UI/UX):

## Ползунок длины пароля:
- [ ] Перетащите ползунок влево и вправо. Счетчик длины над/рядом с ползунком должен мгновенно и плавно менять цифры от 5 до 40.
- [ ] Бегунок имеет идеально круглую форму, а при наведении курсора (hover) слегка увеличивается в масштабе.

## Чекбоксы настроек:
- [ ] Нажатие на текст должно активировать/деактивировать чекбокс.
- [ ] При активации чекбокс плавно окрашивается в неоново-зеленый цвет, а внутри появляется контрастная галочка.

## Адаптивность:
- [ ] Откройте DevTools (F12) в браузере и включите адаптивный режим (Ctrl+Shift+M).
- [ ] Уменьшите ширину экрана до `360px`–`480px`.
- [ ] **Ожидаемое поведение:** Элементы `label` сохраняют строку, текст пропорционально уменьшается, а чекбоксы жестко удерживают свой размер и не сжимаются. Ползунок растягивается на 100% доступной ширины.

---

# 2. Тестирование буфера обмена:

- [ ] Сгенерируйте пароль.
- [ ] Кликните по инпуту результата `#passwordResult`.
- [ ] **Ожидаемое поведение на ПК:** Текст выделяется, рамка инпута меняется на сплошную, фон подсвечивается зеленым, а текст временно меняется на «Скопировано! 👍». Через 1.5 секунды исходное значение возвращается.
- [ ] **Ожидаемое поведение на Телефоне:** При тапе по инпуту происходят те же визуальные эффекты, но мобильная экранная клавиатура **НЕ выезжает**.
- [ ] Вставьте скопированный текст в любое другое место, чтобы убедиться, что пароль действительно в буфере.

---

# 3. Тестирование PWA и Офлайн-режима:

## Регистрация Сервис-Воркера:
1. Откройте сайт по ссылке или через Live Server.
2. Откройте DevTools (F12) -> вкладка **Application** -> слева выберите **Service Workers**.
3. [ ] Статус воркера должен быть: `activated and is running`.

## Проверка работоспособности без интернета:
1. Во вкладке DevTools **Network** (или Application -> Service Workers) поставьте галочку **Offline** (или полностью отключите Wi-Fi на компьютере/телефоне).
2. Обновите страницу через Ctrl+F5 (жесткая перезагрузка).
3. [ ] **Ожидаемое поведение:** Сайт успешно загружается, не показывая стандартную ошибку браузера «Нет интернета». Кнопка генерации продолжает создавать новые пароли локально в памяти.

# 4. Установка приложения на устройство:
- [ ] **В браузере Edge/Chrome на ПК:** В правой части адресной строки должна появиться кнопка «Доступно приложение. Установить».
- [ ] **На Android:** В меню браузера должна быть активна кнопка «Установить приложение» / «Добавить на главный экран». При запуске с экрана приложение открывается без адресной строки браузера.
- [ ] **На iOS (Safari):** Меню «Поделиться» -> «На экран "Домой"» успешно создает иконку приложения. При запуске с экрана приложение открывается без адресной строки браузера.
